## API clima e CEP (Open-Meteo & ViaCEP)
> Exemplo de uso de APIs em Python usando a biblioteca `requests`.

**[Acesse a Documentação Completa das APIs](https://github.com/mercury063/API-clima/blob/main/docs.md)**

## AVISO
- O código exige o Python instalado no ambiente
- Após a instalação do Python e do Git, utilize `git clone https://github.com/mercury063/API-clima.git` para clonar o **repositório**
- Dentro da pasta **API-clima**, execute `pip install -r requirements.txt`
- Para executar o programa, utilize `python script.py` no Windows **ou** `python3 script.py` no Linux
