## API clima (Open Mateo)
> Exemplo de uso de API em python usando a lib resquest.


## AVISO
- O codigo exige o python instalado no ambiente
- Após a instalação do python e do github, utilize ```git clone https://github.com/mercury063/API-clima``` para clonar o **repositório**
- Dentro da pasta **API-clima**, execute ```pip install -r requirements.txt```
- Para executar o programa, utilize ```python script.py``` no windows **ou** ```python3 script.py``` no linux
